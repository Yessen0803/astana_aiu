# astana_aiu — Дәмді жоспар

Қазақ тіліндегі айлық ас мәзірі мен азық-түлік тізімі. Күнтізбеден күнді таңдап, тағам мен адам санын белгіле — сайт сол айға керек өнімдерді біріктіріп, жалпы мөлшерін автоматты есептейді.

## Іске қосу

Node.js 20.9 немесе одан жаңа нұсқасы және pnpm қажет.

```bash
pnpm install
pnpm dev
```

Браузерде `http://localhost:3000` мекенжайын аш. Жобаны жариялауға дайындау үшін `pnpm build` командасын орында.

Әр тағамның бастапқы құрамы төрт адамға есептелген. Мәзір мен сатып алу белгілері браузерде сақталады.
