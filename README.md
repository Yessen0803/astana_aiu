# astana_aiu — «Дәмді жоспар»

## О проекте

«Дәмді жоспар» — сайт на Next.js для планирования месячного меню и списка покупок. Интерфейс сайта на казахском языке.

## Что делает сайт

- Показывает календарь на выбранный месяц.
- Позволяет выбрать блюдо на каждый день и указать количество порций.
- Автоматически объединяет одинаковые продукты и считает их общий объём.
- Позволяет отмечать купленные продукты.
- Сохраняет меню и список покупок в браузере.

Например, если запланировать плов три раза в месяц для четырёх человек, сайт посчитает рис — 900 г, мясо — 1,2 кг и морковь — 6 штук.

## Чем полезен

Сайт помогает заранее спланировать питание на месяц, составить список продуктов и купить нужное количество. Это экономит время, упрощает покупки и помогает не брать лишние продукты.

## Роли команды

- **Frontend-разработчик** — страницы, календарь, меню и список покупок.
- **UI/UX-дизайнер** — внешний вид и удобство использования сайта.
- **Разработчик логики приложения** — подсчёт и объединение продуктов с учётом порций.
- **Редактор контента** — казахские тексты и рецепты.
- **Тестировщик (QA)** — проверка работы календаря, расчётов и отображения на разных экранах.
- **Backend-разработчик** — в текущей версии отдельный сервер не используется; данные сохраняются в браузере.
