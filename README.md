# astana_aiu — «Дәмді жоспар»

## О проекте

«Дәмді жоспар» — приложение для планирования месячного меню и списка покупок. Интерфейс приложения казахский. Проект построен на Next.js с App Router.

## Что умеет сайт

- Показывает календарь на выбранный месяц.
- Позволяет выбрать блюдо для каждого дня.
- Даёт настроить количество порций.
- Автоматически объединяет одинаковые продукты и пересчитывает их общий объём.
- Позволяет отмечать уже купленные продукты.
- Сохраняет меню и отметки покупок в браузере.

Например, если запланировать плов три раза в месяц для четырёх человек, список покупок посчитает рис — 900 г, мясо — 1,2 кг и морковь — 6 штук.

## Чем полезен проект

План меню помогает заранее понять, какие продукты и в каком количестве понадобятся на месяц. Так проще организовать покупки, контролировать расходы, не покупать лишнее и каждый день быстрее решать, что приготовить.

## Роли команды

Ниже перечислены роли, подходящие для разработки проекта. Участников и распределение ролей можно добавить по именам, когда состав команды будет известен.

| Роль | Задачи в проекте |
| --- | --- |
| Frontend-разработчик | Создание страниц, календаря, выбора блюд, списка покупок и адаптации для мобильных экранов. |
| UI/UX-дизайнер | Продумывание структуры, внешнего вида и удобного сценария: выбрать день, блюдо и количество порций. |
| Разработчик логики приложения | Расчёт ингредиентов для нескольких блюд и порций, объединение одинаковых продуктов и подсчёт итоговых количеств. |
| Редактор контента | Подготовка казахских текстов интерфейса и списка блюд с ингредиентами. |
| Тестировщик (QA) | Проверка календаря, расчётов, сохранения меню и удобства на разных размерах экрана. |
| Backend-разработчик | Отдельный backend в текущей версии не используется: данные хранятся в браузере. Для общей учётной записи, синхронизации между устройствами и базы данных понадобится backend. |

## Технологии

- Next.js (App Router)
- React
- TypeScript
- CSS
- `localStorage` для сохранения данных в браузере

## Запуск проекта

Нужны Node.js версии 20.9 или новее и pnpm.

```bash
pnpm install
pnpm dev
```

Откройте `http://localhost:3000` в браузере. Production-сборка запускается командой:

```bash
pnpm build
pnpm start
```
