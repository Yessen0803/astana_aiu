# HealthFlow acceptance criteria

Бұл құжат функцияны дайын деп қабылдамас бұрын тексерілетін шарттарды анықтайды. Checklist-тегі белгі қойылмаған тармақ — тексеруді немесе іске асыруды әлі қажет етеді. Қазіргі Next.js нұсқасының бірқатар дерегі браузердің жергілікті жадында сақталатын демо екенін ескеріңіз.

## 1. Тіркелу және профиль

- [ ] Қолданушы аты, email және қала өрістерінің әрқайсысында түсінікті атау мен қате мәтіні бар.
- [ ] Қате енгізілген өрісті түзету басқа дұрыс енгізілген мәндерді өшірмейді.
- [ ] Профиль фотосын жүктеу кезінде файл түрі мен көлемі тексеріледі; қате болса, бұрынғы фото сақталады.
- [ ] Профильді және оның баптауларын сақтау нәтижесі қолданушыға көрсетіледі.
- [ ] Профильді өңдеу ішінде Instagram және TikTok сілтемелерін сақтауға арналған әлеуметтік желілер блогы бар.
- [ ] Әлеуметтік сілтемелер қайта ашқанда сақталған күйде көрінеді; жарамсыз URL сақталмайды.
- [ ] Серверлік тіркелу дайын болғанша интерфейс демо профильді толыққанды аккаунт ретінде көрсетпейді.

## 2. Тамақтану және калория

- [ ] Қолданушы күнді, айды, таңғы ас, түскі ас немесе кешкі ас сүзгісін таңдай алады.
- [ ] Таңғы ас, түскі ас және кешкі астың әрқайсысында өзіне арналған дәл 10 тағам нұсқасы көрсетіледі.
- [ ] Әр тағамның порциясы граммен және калориясы ккал түрінде көрсетіледі.
- [ ] Порция грамы өзгергенде ккал мәні қайта есептеледі және тәуліктік жиынтық жаңарады.
- [ ] Бос, нөлден төмен немесе жарамсыз грамм мәніне нақты қате хабарламасы беріледі.
- [ ] Тағам қосылғанда экранда растау көрсетіліп, таңдалған күнге сақталады.
- [ ] Калория мәні есептік көрсеткіш екені және медициналық кеңес еместігі түсінікті.

## 3. Жоспар, қозғалыс, күтім және ұйқы

- [ ] Қолданушы күндік жоспардан ай көрінісіне ауысып, күнді таңдай алады.
- [ ] Қадам саны тек теріс емес бүтін сан ретінде қабылданады; сақтау соңында нәтиже бірден жаңарады.
- [ ] Жаттығуды таңдау немесе қадам енгізу Прогресс бөліміндегі тиісті күндік/апталық қорытындыға түседі.
- [ ] Ұйқы басталған және аяқталған уақыттан, түн ортасынан өту жағдайын қоса, ұзақтық дұрыс есептеледі.
- [ ] Ұйқы салыстыруы тек жазбасы бар күндерді пайдаланады; дерек жоқ күн нөл деп саналмайды.
- [ ] Әдет белгіленгенде немесе күнделікті жазба сақталғанда сәттілік күйі көрсетіледі.

## 4. Прогресс және хабарландырулар

- [ ] Апта және ай көріністері таңдалған уақыт аралығына сәйкес келеді.
- [ ] График пен қорытындыда өлшем бірлігі және дерек аралығы көрсетіледі.
- [ ] Бос кезеңге түсінікті бос күй ұсынылады; нөл мен жазбаның жоқтығы ажыратылады.
- [ ] Тамақ немесе белсенділік жоспарланғанда еске салу жасалып, хабарландырулар тізімінде көрсетіледі.
- [ ] Хабарландыруды ашу оны негізгі қолданба макетінің ішінде ашады; сол жақ «МӘЗІР» навигациясы көрініп, қолдануға жарамды қалады.
- [ ] Хабарландыру мәліметі бетінде «← Қосымшаға қайту» әрекеті бар; ол бұрынғы бөлімге қайтарады.
- [ ] Бүйір мәзірдегі «Хабарландырулар» бетінде тек оқылған хабарламалар көрсетіледі.
- [ ] Жоғарғы қоңырау мәзірінде тек оқылмаған хабарламалар көрсетіледі; badge саны оқылмағандар санына тең.
- [ ] Жоғарғы қоңыраудан хабарлама ашылғанда ол оқылған күйге ауысып, бүйір мәзірдегі тізімге қосылады.
- [ ] «Барлығын оқылды деп белгілеу» және өшіру әрекеттері оқылған/оқылмаған топтың өзіне ғана әсер етеді.

## 5. Қауымдастық және достар

- [ ] Пост жариялау алдында мәтін мен фотоның алдын ала көрінісі көрсетіледі.
- [ ] Жарамсыз фото немесе сақтау қатесі туралы хабарлама көрсетіліп, жазба мәтіні сақталады.
- [ ] Лайк пен пікір әрекеті саны/күйі бойынша көрінетін кері байланыс береді.
- [ ] Пікірге мәтін немесе стикер жіберуге болады; стикер пікірлер тізімінде көрінеді.
- [ ] «Ұсыныстар» лентасында басқа қолданушылардың жазбалары көрсетіледі; оларға лайк пен пікір қалдыруға болады.
- [ ] Дос қосылғанда оның картасы тізімде көрінеді; картаны ашқанда толық профиль көрсетіледі.
- [ ] Жеке деректер мен прогресс тек қолданушы таңдаған кезде ортақтасады.

## 6. Қала, орындар және брондау

- [ ] Қала таңдау орындар тізімі мен қолжетімді белсенділіктерге әсер етеді.
- [ ] Сүзгілерді тазарту және нәтиже жоқ күйінен шығу жолы бар.
- [ ] Өтінімде орын, күн, уақыт және адам саны анық көрсетіліп, жіберілген соң расталады.
- [ ] Серверлік орын провайдері қосылмайынша демо брондау “өтінім сақталды” деп белгіленеді, “бронь расталды” деп емес.

## 7. AI чат, қолдау және админ

- [ ] Чат сәлемдесуге және HealthFlow тақырыбындағы жиі сұрақтарға қолданушы таңдаған тілде жауап береді.
- [ ] AI білмейтін сұраққа сенімді емес жауап ойлап шығармайды; адам қолдауына өтуді ұсынады.
- [ ] Қолдау хабары жіберілген, жеткізілген немесе сәтсіз күйімен көрсетіледі; сәтсіз хабарды қайта жіберуге болады.
- [ ] Әкімшінің жауап беру мүмкіндігі қолданушы интерфейсіндегі рөл атауына ғана емес, сервердегі рұқсатқа сүйенеді.
- [ ] Әкімші көрінісінде қолдау сұрауларының күйін ажыратып, дұрыс диалогқа жауап жіберуге болады.

## 8. Тіл, тақырып, қолжетімділік және қауіпсіздік

- [ ] Қазақша, орысша және ағылшынша аудармаларда аударылмаған негізгі басқару элементтері қалмайды.
- [ ] Ашық/қара тақырып ауысқанда мәтін, жиек, енгізу өрістері, диалогтар және меңзер күйі оқылатын болып қалады.
- [ ] Қара тақырып Тамақтану бөліміндегі айлық жоспарды, тағам карточкаларын, ашылмалы тізімдерді және бос/қате күйлерді де қамтиды; бет фоны #121212, негізгі карточка беті #1a1a1a түстеріне сай.
- [ ] Негізгі функциялар пернетақтамен басқарылады; фокус белгісі көрінеді; диалог ашылғанда фокус дұрыс ауысады.
- [ ] Қате мен сақтау күйі тек түспен ажыратылмай, белгіше/мәтін және экраннан оқитын бағдарламаға арналған хабармен беріледі.
- [ ] Телефонда көлденең сырғыту қажет болмайды; негізгі батырмалар басуға жеткілікті үлкен.
- [ ] Денсаулық деректері мен аккаунтқа қатысты әрекеттер серверде тексерілмейінше өндіріске дайын деп қабылданбайды.

## Жұмысты қабылдау өлшемдері

- [ ] Тиісті қабылдау шарттары орындалған немесе кейінге қалдыру себебі GitHub Issue ішінде жазылған.
- [ ] Қалыпты, бос, қате және сәтті күйлер қаралған.
- [ ] Қазақша, орысша, ағылшынша және ашық/қара тақырыпқа әсері қаралған.
- [ ] Pull request тиісті Issue-ге байланыстырылған және өзгерісті қысқаша түсіндіреді.
- [ ] README және API/дизайн құжаттары іске асқан мүмкіндіктерге сәйкес жаңартылған.
